## 🎯 ¿Qué es este proyecto?
Es una web y sistema de captación para clases particulares de **Estadística** y **Estadística Avanzada** impartidas por Jesús para alumnos universitarios.

### Componentes clave del proyecto:
1. **Página web principal (`index.html`, `styles.css`, `script.js`):**
   - Landing page optimizada para móvil y escritorio.
   - Detecta parámetros por URL (`?c=1` para Estadística, `?c=2` para Estadística Avanzada) para preseleccionar la asignatura.
   - Opciones: Intensivo (preparación para exámenes de enero), Grupos reducidos (40 €/mes), e Individual (18 €/h).
   - Botón directo de contacto a WhatsApp.
   - Contador de descuento del 10% activo hasta el 20 de noviembre.

2. **Página de descarga de carteles (`carteles-intensivo.html` y `carteles.html`):**
   - Web accesible desde el móvil o navegador para ver y descargar los carteles en alta resolución (300 DPI, 2400 × 3360 px) listos para imprenta.
   - Carteles con descuento (válidos hasta el 20 de noviembre: 108 € en vez de 120 €).
   - Carteles sin descuento (120 € fijos para usar después del 20 de noviembre).

3. **Imágenes y recursos:**
   - Carteles PNG generados con alta calidad.
   - Códigos QR dinámicos que llevan a la web con la asignatura preseleccionada.
